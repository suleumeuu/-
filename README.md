# С++ машинаға бағытталған бағдарламалау — электронды оқу құралы

Бұл жоба GitHub Pages-ке тікелей жариялауға арналған статикалық электронды кітап.

## Ішінде бар
- 1-бет: заманауи C++ мұқабасы;
- 2-бет: электронды оқу құралы туралы мәтін;
- 3-бет: интерактивті мазмұн;
- дәрістердің толық мәтіні бастапқы дәрістер жиынтығынан;
- зертханалық жұмыстардың толық мәтіні бастапқы зертханалық жұмыс құжатынан;
- мазмұндағы әр дәріс пен зертханалық жұмыс өз бетіне бір шерту арқылы апарады;
- әр зертханалық жұмыстан кейін қазақ тіліндегі C++ YouTube бейнесабақтары;
- алдыңғы/келесі бет батырмалары және пернетақтадағы ← → навигациясы;
- қараңғы режим және толық экран;
- бастапқы PDF материалдары `source/` ішінде.

## GitHub Pages-ке шығару
1. GitHub-та жаңа repository ашыңыз, мысалы: `cpp-machine-oriented-ebook`.
2. Осы папкадағы барлық файлды repository-ге жүктеңіз.
3. `Settings` → `Pages` бөліміне кіріңіз.
4. `Build and deployment` → `Deploy from a branch` таңдаңыз.
5. Branch ретінде `main`, folder ретінде `/ (root)` таңдаңыз.
6. `Save` басыңыз.
7. Бірнеше минуттан кейін GitHub Pages берген URL арқылы кітап ашылады.

## Жергілікті тексеру
`index.html` файлын тікелей ашуға болады. Ең дұрысы локальды сервер қолдану:

```bash
python -m http.server 8000
```

Сосын `http://localhost:8000` адресін ашыңыз.

## Дереккөздер
Дәрістер мен зертханалық материалдар пайдаланушы ұсынған `Дәрістер жиынтығы.docx` және `Зертханалық жұмыстар.doc` файлдарынан алынып, PDF беттеріне негізделіп веб-беттерге орналастырылды.
